# Manus preview WebView wrapper

This repository contains a minimal Android WebView wrapper that opens the provided Manus preview URL.

App name: Medicine Reminder
Package: com.preview.manus

To build locally: open the project in Android Studio and build APK (Build -> Build Bundle(s) / APK(s) -> Build APK(s)).

The repository includes a GitHub Actions workflow that builds a debug APK on push to main and uploads the APK as an artifact.

CI trigger: Commit created to start APK build.
